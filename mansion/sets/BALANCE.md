Every set re-solves all thirteen mansion problems at full length, and each later set re-solves every
optional problem the earlier sets opened. That repetition, not the new material, is what makes set 4
nearly twice set 1.

## The rule (doc, 12:29)

The first movement explains each idea fully, at the place it first pays rent. After that it's quoted in
shorter and shorter forms: a highlights reel, so the reader gets to the new stuff. Terminology still has
to be introduced (in set 1, or where a level's word first lands), never re-explained in full.

## Per movement

- **Set 1:** the thirteen problems, slow, with the full first-use explanations (arrows at the spool,
  the dot at spool part 4, crosses, senses, the slow walk to τ). Grows to about 36-38k.
- **Set 2:** the thirteen problems as highlights, except where a level-2 word first lands (heft, punch,
  hook, profile, pickup, crank, spin, can, coil): those spots stay full. Set 1's explanations become one
  line each ("Rolling →, the spool turns back around; the torques add to (Fr + fR) ↺"). The seven
  drawers are new, so they're full. Target ~34-36k.
- **Set 3:** mansion problems shorter still, full only where level-3 words land (zip, zing, still
  point, flips, tone/chord/beat, trade, stripe, shift/stretch); drawers as highlights; funhouse full.
  Target ~35-37k.
- **Set 4:** mansion problems and drawers as highlights, funhouse short, understage full; the level-4
  words (one machine, zam/zlam, TEST and RUN, zow/zlow) full where they land. Target ~35-38k.
